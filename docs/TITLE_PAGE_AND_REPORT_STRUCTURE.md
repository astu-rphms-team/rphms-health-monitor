## Suggested Report Notes

- Keep the writing formal and technical.
- Clearly state that the system is used for monitoring and alerting only.
- Explain why the project is low-cost and practical for academic implementation.
- Highlight the real system pipeline: sensor → ESP32 → backend → database → dashboard → alert.
- Mention the AI assistant as a support feature, not a diagnostic tool.
- Be honest about limitations and future improvements.
